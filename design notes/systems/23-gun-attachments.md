# Gun attachments

Physical `Gun`. Same kit for players and AI. Law file also at artifacts/hypersteel/game design/23-gun-attachments.md

Turn slowdown clamp(H / Strength, 0, 0.50). Rifle H=0.30. Human str 1 = 30%. Str 10 = 3%. Ryko 0.3% is str 10 plus extra-limb / sequences perk.
Reload *= kit / (Agility / UseTime).

Slots: Optic, Muzzle (per ammo family), Barrel, Stock, Mag (grip/std/box), Under, Rail, Hopup (one).

Pistol collapsing brace = huge accuracy when extended.
Muzzle illegal across ammo families.
Code: Scripts/Weapons/Attach/ + Gun.Kit
