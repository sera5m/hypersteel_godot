# Player controls

Default keyboard / mouse. Rebindable later. Same verbs for campaign and MP.

ADS zoom is an optic, not a fire mode. Attachments change the zoom. Menu: ADS hold or toggle.

## Mouse

| Input | Does |
|---|---|
| LMB | Primary fire |
| RMB | Secondary / alt on this gun. Not ADS |
| MMB | ADS. Hold or toggle from options. Default hold |
| Scroll up / down | Weapon ++ / -- |
| T | Paint target (Apex MMB ping / mark) |

## Hands and items

| Input | Does |
|---|---|
| E | Interact. Context, never a second fire |
| F | Melee. Left-hand toggle (12) |
| Q | Grenade |
| R | Reload |
| X | Sling. Right-hand gun away |
| Tab | Inventory |
| I | Inspect gun (anim, attach points) |
| U | Configure gun popup (same kit, no anim) |

E context: fist = grab; melee-out = charge/recall; gun focus + HasModeSwitch = mode; inspect = cycle attach; world = door/pack/turret.

## Move

| Input | Does |
|---|---|
| Space | Jump |
| Shift | JumpKit pulse |
| Ctrl | Speed under 4 m/s: crouch. Faster: slide |
| Alt | Prone |
| C | Boost (Titanfall-style extra, not the backpack) |

## Kits and call-in

| Input | Does |
|---|---|
| Caps Lock | Use ability (shield pack, cloak drone) |
| Z | Call-in menu (walker, air strike, radio pack) |
| 1-6 | Weapon slots |
| Y or Enter | Chat |
| F1 | Emote wheel |

Do not collide: RMB != ADS. E != melee (F). Shift is kit. C is boost. Caps is backpack. Z is call-in.
