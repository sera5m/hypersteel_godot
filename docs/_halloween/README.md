# Halloween afterlife notes (non-canon, secret)

This folder is design notes for a non-canon Halloween special. It is not campaign bible. It is not the living-world obelisk turrets.

Do not treat these as systems to implement on the main campaign path unless a later decision explicitly promotes them.

## Files

- `afterlife.md` — what the afterlife is made of, how space works, mood
- `souls.md` — soul shapes by neuroanatomy (human/catgirl, robot, Ryko)
- `bestiary.md` — afterlife-only creatures
- `obelisk-rats.md` — afterlife 4D “obelisks” vs living-world obelisk turrets
- `exits-and-plasma.md` — leaving the afterlife, telefrag swap, energy handwave, respawn rules
- `pocket-100m3.md` — collision pocket when two violent exits interfere
- `plot-hooks.md` — Valkarie, Enduring, mini-bosses, scripted-death branches
- `post-event.md` — what remains after Halloween
- `secrets-lineage.md` — White Knuckle / Ultrakill / April Fools secret grammar
